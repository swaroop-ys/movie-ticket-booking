# 🎬 Movie Ticket Booking Calculator

A simple Python-based Movie Ticket Booking Calculator that calculates the final ticket price based on age eligibility, seat type, membership discounts, show timing, and additional charges.

## 🚀 Features

- Age-based ticket booking eligibility
- Evening show eligibility checking
- Membership discount calculation
- Weekend and evening extra charges
- Seat-based service charges (Premium, Gold, and Regular)
- Automatic final ticket price calculation
- Booking success or failure status

## 🛠️ Technologies Used

- Python 3
- Conditional Statements (`if`, `elif`, `else`)
- Logical Operators (`and`, `or`)
- Variables and Data Types
- Arithmetic Operations
